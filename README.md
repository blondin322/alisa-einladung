# Einladung für Alisa

Страница-приглашение на немецком. Друзья открывают её по QR-коду с бумажной карточки. Праздник: суббота, 7 ноября 2026, 10:00–14:00, Königsberger Straße, Germersheim.

На экране только улица и город. Полный адрес есть лишь внутри кнопкй маршрута. Про дресс-код и подарки на странице ничего нет.

## Локально

```bash
npm install
npm run dev
```

Приглашение: http://127.0.0.1:43123

Карточка для печати: http://127.0.0.1:43123/karte/

Сборка: `npm run build`. Готовые файлы лежат в `dist/`.

## QR перед печатью

В [`src/party.ts`](src/party.ts) замените `siteUrl` на настоящий адрес GitHub Pages, например `https://имя.github.io/репозиторий/`. Пока там заглушка `https://example.github.io/alisa/`, на карточке виден предупреждающий текст, и его не печатают.

Дальше откройте `/karte/`, в диалоге печати выберите A6 и поля «нет».
